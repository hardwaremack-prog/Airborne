# Airborne! — 1984 Macintosh tribute remake

A browser remake of **Airborne!**, the black-and-white 1984 Macintosh arcade game from Silicon Beach Software.
It's one self-contained `index.html` with no assets and no install. Open it in any modern browser and play.

## How to play
You command the anti-aircraft gun at the bottom of the screen.

| Action | Mouse / touch | Keyboard |
|---|---|---|
| Aim | move the pointer | ← → or A D |
| Fire | click / hold | Space |
| Pause | | P |
| Sound on/off | | M |
| New game | | N |

- **Helicopters** drop paratroopers. Shoot a canopy and the trooper drops like a stone. If he lands on a buddy, that one goes down too.
- If **4 troopers land on the same side**, they march over, climb the bunker and blow up your gun.
- **Wave 2+:** jets dive-bomb the bunker. Shoot the bombs out of the sky.
- **Wave 3+:** tanks roll in and shell you. Aim low; each tank takes 3 hits.
- Clear a wave without anyone landing to earn a **perfect-defense bonus**.

Scoring: Helicopter 10 · Jet 25 · Trooper 5 · Bomb/Shell 5 · Tank 50. You start with 3 guns, and your high score is saved in the browser.

## Features
- Authentic 1-bit look: 512×320 playfield, dithered patterns, a Mac-style menu bar and striped title bar, pixel-perfect integer scaling
- Synthesized sound effects (Web Audio): gunfire, explosions, helicopter chop, jet roar, bomb whistles, and a spoken "Airborne!" at start
- Works on desktop, Raspberry Pi (Chromium) and touch screens
